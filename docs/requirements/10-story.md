## 1. Cutscene engine (`src/cutscene.js`)

- Scripted non-interactive sequences reusing the canvas stack: background on `#bg-canvas` (aspect-covered image or color; `redrawBottom` yields while active), characters on `#game` (cleared per frame), shared camera `translate(-x,-y) scale(zoom)`. Wind hidden, parallax hidden, HUD/menus/hotbar hidden (main menu + chrome hidden so the cutscene bg is visible). Physics frozen (`cutsceneActive` blocks input/placement/aim); loop still runs `updateCutscene(dt)` + `renderCutscene(bgCtx,fgCtx)`.
- Camera: `keyframes[{t,x,y,zoom,easing}]` (`t` may be negative for intro; `zoom 0.5–3`); `linear|easeIn|easeOut|easeInOut` cubic; default `{0,0,1}`.
- Characters: `[{id,src,frame?,sprite?,character?,x,y,scale,anchor,zIndex,visible,keyframes?[{t,x,y,scale,sprite?,frame?,src?,easing}]}]`; `src` relative `./img/...`; `frame{x,y,w,h}` cropped via 9-arg `drawImage` (same single blit); `sprite` id `^[a-z0-9][a-z0-9-_]{1,40}$` resolved via `src/character-sprites.json` (`loadSpriteLibrary`/`getSprite`; flat or `{version,characters,sprites}`); `character` groups filter editor sprite lists; per-keyframe `sprite` snaps (no interp); `x/y` may start off-screen (`-1000…LOGICAL+1000`); `scale 0.2–3`.
- Dialogs (HTML `#cutscene-dialog`, JRPG box per §3): `[{t?,auto?,speaker?,text(1–500,\n ok),cps(10–60,def 20),duration?(0–60000,empty=stay),portrait?(./img/... or sprite id),portraitSide?(left|right,def left)}]`; `t null/auto` → starts after previous (`effectiveT+reveal+duration`; first at 0). Typewriter `revealed=min(len,floor((now-start)*cps/1000))` + `▌` cursor. `Space`/`R`/click fast-forwards (reveal → advance → close if last); `Escape`/`Enter` also advance; camera/chars keep interpolating.
- Title intro/outro (optional, backward-compat): `intro{blackMs,titleFadeMs,holdMs,fadeInMs(0–10000),title?,enabled?}` + `outro{fadeOutMs}` (flat aliases accepted). Timeline: black → title ramp → hold → fade-in (content `contentTime=max(0,elapsed-introBeforeFade)` runs during fade; frozen at 0 before); fade-out freezes last frame behind `0→1` black, hides dialog. `#cutscene-title-overlay` (`absolute inset black z13`, `#cutscene-title-text 700 28–32px` animated opacity/scale/rise). Intro `Space`/`R`/click skips to content; fade-out input/skip completes. `isCutsceneActive()` true throughout.
- JSON: one file per cutscene `src/cutscenes/<id>.json` only (`id ^[a-z0-9][a-z0-9-_]{2,40}$`); `src/cutscenes.json`/`src/cutscene-data.json` deprecated (absent or `[]`, never fetched). Unknown fields ignored. `validateCutscene()` enforces ranges; `playCutscene` rejects invalid with `console.warn`.
- API: `loadCutscene(id)` (folder only, cached), `listCutscenes()`/`loadCutscenesFromFolder()`, `playCutscene(idOrData,{onComplete})`, `isCutsceneActive()`, `getActiveCutsceneId()`, `getCutsceneTime()`, `updateCutscene(dt)`, `renderCutscene`, `handleCutsceneInput(e):bool`, `skipCutscene()`, `validateCutscene()`, seen helpers `hasSeenCutscene/markCutsceneSeen/loadSeenCutscenes` (`CUTSCENE_SEEN_KEY="golfVectorField.cutscenes.seen.v1" {version:1,seen:[]}`; cleared on storage clear/regeneration).
- Skip: `#cutscene-skip-button` (`Skip »`, absolute `top:10 right:12` z14, pill `700 11px` on `rgba(0,0,0,0.55)`) visible iff active (synced on start/complete/every cutscene tick; `preventDefault`+`stopPropagation` → `skipCutscene()` → `onComplete`).

## 2. Cutscene triggers (no shop/loadout)

- `prologue` (`src/cutscenes/prologue.json`): first click on `The Proving Grounds` with no restorable save and no active cutscene → preload prologue + intro-3-hole, play prologue → mark seen → chain §2 `intro-3-hole` (back-to-back, no menu/splash/HUD between) → mark seen → hole-1 banter flow (see `09-tutorial.md` + §5). Seen → go straight to banter flow. Non-tutorial courses never trigger it. Load/validate failure → fall through to banter flow.
- `intro-3-hole`: only as the second half of the prologue chain above (never standalone on later clicks).
- `first-restock` (`src/cutscenes/first-restock.json`): first Proving Grounds Hole-1→Hole-2 transition, before `loadLevel(1)` (no Hole-2 glimpse), once. Replay skips. Failure → continue to bag grant + banter.
- `end-9-hole`: first 9-hole final `WIN` clear (`runFirstCourseClear`, not active): hide Victory → play → mark seen → points summary (see `07-rewards-and-economy.md`). Skipping lands at the summary. `End Run`/Game Over never trigger it. Failure → summary directly.

## 5. Banter (`src/banter.js`, `src/banter.json` + `src/tutorial-banter.json`)

- In-place May/Caddy dialog on the loaded hole (terrain/ball/wind visible behind; never takes over `bgCtx`). Files share schema `{version:1, banters:[{id ^[a-z0-9][a-z0-9-_]{1,40}$ unique across both, lines[1–12 × {speaker:may|caddy, text:1–500}]}]}`; loader fetches both in parallel and merges (`getBanter` merged; `listBanterIds` rotation pool only; `listTutorialBanterIds`; `listAllBanterIds`; `TUTORIAL_BANTER_IDS` guards legacy single-file). Invalid entries ignored (fall through to banner). Tutorial ids: `controls-first`, `tutorial-field-modifiers` (alias `stacking-third`), `tutorial-rewards` (alias `rewards-second`), `tutorial-passives`, `tutorial-hole1-liquifier-3`, `tutorial-hole1-liquifier-10`, `tutorial-hole3-rotator-reminder`, `tutorial-hole2-gadgets-reminder`, `tutorial-hole4-complete` (+ legacy `attempts-fourth`, `tutorial-liquifier-reminder` kept, unused).
- Presentation: existing `#cutscene-dialog` JRPG box, `portrait-left`; May (`May`, `./img/cutscenes/portrait-may.png`), Caddy (`Caddy`, `./img/cutscenes/portrait-caddy.png`). `BANTER_CPS=20`, `BANTER_LINGER_MS=1000`, auto-chain. `Space`/`R`/click/Escape/Enter: reveal → advance (skip linger) → close on last. No Skip design beyond §6.
- Tutorial (only on Proving Grounds; replay every run; never touch the shuffle bag): hole-1 `controls-first` (arrows/space/r/escape/left-click/right-click/hotkeys), hole-2 `tutorial-field-modifiers` (liquifier keep-direction, deflector/rotator redirect, magnifier power, stacking/snap/split), hole-2 `tutorial-hole2-gadgets-reminder` at 5 attempts (gadget + old man), hole-3 `tutorial-rewards` (4-slot bag, discard, hole/treasure rewards, attempt balance), hole-4 `tutorial-passives` (stackable passives, `+20% area`/`+20% strength`/free attempts, click toggle), hole-1 `tutorial-hole1-liquifier-3/10` (liquifier + head wind), hole-2 `tutorial-hole3-rotator-reminder` at 3 (rotator + upwards→forward), hole-4 `tutorial-hole4-complete` (congratulations + `Mt. Aeoulus` + 10 attempts + lost modifiers + item management). Thresholds/ordering canonical in `09-tutorial.md`.
- Non-tutorial: first hole-1 start shows one random non-tutorial id from a shuffle bag over `src/banter.json` (each once per cycle, rebuild+reshuffle when empty; `BANTER_STATE_KEY="golfVectorField.banter.v1" {version:1,count,lastId,bag}`); then `Hole 1` banner. Reload mid-banter does not replay.
- Blocking (`src/main.js` + `src/banter.js`): API `loadBanterFile/preloadBanterFile/getBanter/list*/validateBanter/isBanterActive/getActiveBanterId/playBanter/playRunStartBanter/updateBanter/handleBanterInput:bool/skipBanter`. While active: `update` ticks wind + banter only (physics frozen, charge cancelled); all game input (`Space` via `BANTER` getter, aim/launch/`1–4`/place/drag/`R`/`H`/`Escape`/`P` pause) blocked; cutscene branch keeps priority; never overlaps cutscene.
- Skip: `#banter-skip-button` (same pill/position/z14 as cutscene skip) visible iff banter active (synced on start/complete/every banter tick; `preventDefault`+`stopPropagation` → `skipBanter()` → `onComplete`).
